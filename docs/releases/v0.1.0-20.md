# RPM/DEB 0.1.0-20 — community updates (beta)

This release combines community PRs #5–#8 with support for the current official
Power BI Desktop **2.160.1151.0** installer.

## Improvements

- Exact installer and assembly checks for Desktop 2.160.1151.0, including the
  WinRT compatibility needed at startup. Earlier validated installers remain
  supported for local installation and maintenance.
- Wine corrections for multi-monitor placement, primary selection handling,
  resize visibility and maximum-date conversion.
- Named-pipe root discovery for tools that connect to an open Desktop session,
  including the integration correction for restarting a directory query.
- Experimental Arch Linux/Omarchy support and Hyprland theme following.
- Automatic setup selects the paired community-fix runtime.

## Installation

```bash
# Fedora 44
sudo dnf install ./powerbi-linux-0.1.0-20.fc44.noarch.rpm
# Ubuntu/Debian (experimental)
sudo apt install './powerbi-linux_0.1.0-20~experimental1_amd64.deb'
pbi-linux setup
```

For an existing managed installation, `pbi-linux update` installs the paired
runtime while preserving the installed Desktop version. Setup installs Desktop
2.160.1151.0 in a fresh installation; update does not upgrade Desktop itself.

The release includes RPM, source RPM, experimental DEB, corresponding CLI sources,
checksums and provenance. Runtime binaries and corresponding sources are provided
in the paired [runtime release](https://github.com/cavallaro88/powerbi-linux/releases/tag/runtime-v0.1.7-pr-integration.1).
Technical validation is recorded in the release evidence and the
[2.160 assessment](../reference/powerbi-2.160.md).
