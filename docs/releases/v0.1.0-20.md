## Testing the complete pair

The packages contain the CLI and source recipes, not Wine or Microsoft binaries.
Automatic setup still selects published runtime **0.1.6-beta.1**. That runtime
can run the new Desktop recipe, but does **not** contain the PR #6/#8 Wine fixes.
Do not describe automatic setup with this pin as delivery of those Wine fixes.

For a fresh, disposable installation, use the separately built integration
runtime with the new package:

```bash
pbi-linux setup \
  --runtime ./powerbi-linux-runtime-0.1.7-pr-integration.1-x86_64.tar.xz \
  --runtime-sha256 0128b0f2bb2d4ab098767f96f9492223015df6f57d28d954170e0e031a5ae482
```

Setup prompts for license acceptance and verifies the exact Microsoft download.
For an existing installation, `update --runtime ... --runtime-sha256 ...` changes
its runtime in place and preserves its installed Desktop version. Back up reports
before maintenance. It does not upgrade Desktop to 2.160.

The runtime archive is an immutable build from the integration tree before the
2.160 CLI port. Its embedded default Desktop record is older; the new CLI owns
the selected exact recipe and stages its current WinRT shim before compilation.
Its binary checksum and existing build provenance must remain unchanged.

session. The new runtime still needs the Fedora 44 graphical release matrix.
